# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:16-11-2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

1. Open the CAD software on the computer and create a
new part or design file. Select the appropriate workspace
for 3D solid modelling.

2. Set the document units to millimetres (mm). Study the
given engineering drawing carefully and identify the top
view, sectional views, dimensions, and isometric view of
the component.

3. Observe the overall geometry of the component and
identify its main features, including the base flange, central
circular boss, central bore, mounting holes, raised
portions, and recessed surfaces.

<img width="556" height="236" alt="image" src="https://github.com/user-attachments/assets/088b8aaf-45b2-4e08-ada9-9d29edf632e9" />

4. Select the XY plane and enter the sketching
environment. Draw the outer profile of the base flange
using lines, arcs, and circles according to the dimensions
specified in the drawing.

<img width="796" height="242" alt="image" src="https://github.com/user-attachments/assets/a5608dab-28c4-4dfc-a036-dead747d4203" />

5. Apply the necessary geometric and dimensional
constraints to the sketch so that the profile is fully defined,
properly aligned, and symmetrical.

<img width="746" height="386" alt="image" src="https://github.com/user-attachments/assets/d0c13eec-ac15-4b6c-86aa-d1a31b1693ce" />

6. Finish the sketch and use the Extrude command to
apply the required thickness to the base flange, forming
the main body of the component.

<img width="726" height="825" alt="image" src="https://github.com/user-attachments/assets/bdfbb13b-adb5-4b64-b8c8-e02ce7dfc9ff" />

7. Select the top face of the base flange and create a new
sketch. Draw the concentric circles required for the central
housing and specify their diameters using the
dimensioning tool.

8. Use the Extrude command to raise the circular profile to
the specified height to create the central boss.

<img width="803" height="261" alt="image" src="https://github.com/user-attachments/assets/c832cfd4-037a-4870-ba8f-d1702677f787" />

9. Create a sketch on the upper face of the central boss.
Draw the inner circular profile for the central bore and
apply the required diameter, ensuring concentricity with
the outer circular boss.

10. Use the Hole or Extrude Cut command to remove
material from the central portion and form the required
bore. Add any internal circular steps or recesses indicated
in the sectional view.

11. Select the upper surface of the flange and create a
new sketch for the mounting holes. Draw the required
circles and position them accurately according to the hole
spacing or pitch circle diameter (PCD) specified in the
drawing.

12. Use the Hole or Extrude Cut command to create the
mounting holes through the flange across all required
positions

<img width="736" height="818" alt="image" src="https://github.com/user-attachments/assets/8aa20ea3-ad10-4702-a172-659ac39304d1" />

13. Model any remaining raised portions, ribs, slots, or
stepped surfaces shown in the engineering drawing using
appropriate sketching, extrusion, and cutting operations.

14. Apply the Fillet and Chamfer commands to the
specified edges and corners to remove sharp edges and
create smooth transitions matching the drawing.

15. Inspect the completed 3D model from the top, front,
side, sectional, and isometric views. Verify all dimensions
against the engineering drawing and save the completed
model in the required CAD file format

<img width="653" height="640" alt="image" src="https://github.com/user-attachments/assets/234dcf92-1436-4691-baff-ca7c110754fc" />

16. Generate a 2D drawing sheet from the completed 3D
model containing the required orthographic views,
sectional views, dimensions, and isometric view. Save and
verify the final drawing sheet.
